# Implementation Plan: Portfolio Foundation

**Branch**: `001-portfolio-foundation` | **Date**: 2026-08-14 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/001-portfolio-foundation/spec.md`

## Summary

Replace all Astro Keel template identity and demo content with Joel Samaniego's personal
identity across `src/consts.ts`, `astro.config.mjs`, the home page, the about page, the works
index, and the footer. Delete all demo works and blog content files. The implementation touches
only configuration, page copy, and content files — no new components, no new dependencies, no
architecture changes.

## Technical Context

**Language/Version**: TypeScript 5 / Astro 7 (SSG mode)

**Primary Dependencies**: Astro 7, @astrojs/mdx, @astrojs/sitemap — all existing; none added

**Storage**: Markdown/MDX files in `src/content/blog/` and `src/content/works/` (Astro Content
Collections, file-based, no database)

**Testing**: `npm run build` — the sole validation gate. No unit tests required for content
and config changes.

**Target Platform**: GitHub Pages static hosting at `https://samajoel.github.io/astro-keel`

**Project Type**: Static site — personal portfolio and blog (Astro SSG)

**Performance Goals**: Preserve existing Lighthouse 100/100/100/100; no new assets or scripts
introduced

**Constraints**: No new dependencies. No backend. No new components unless absolutely
unavoidable. Every change must pass `npm run build`.

**Scale/Scope**: ~9 files changed, ~6 files deleted. Single developer, one-time setup.
