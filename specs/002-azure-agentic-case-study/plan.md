## SVG Architecture Diagram Design

**Layout**: Layered top-to-bottom flow within a fixed-width SVG (viewBox responsive).

```
┌─────────────────────────────────────────────────────────────────┐
│  SIMPLIFIED VIEW (default)                                      │
│                                                                 │
│  [User] ──→ [Frontend] ──→ [FastAPI] ──→ [FoundryAgent]        │
│                  │                             │                │
│             [Cosmos DB]               [SQL Query Tool]          │
│             (persistence)                      │                │
│                                           [Azure SQL]          │
│                                               ↓                 │
│                                 ←── [Streaming Response]        │
└─────────────────────────────────────────────────────────────────┘

  [Show full architecture ▼]  ← toggle button

┌─────────────────────────────────────────────────────────────────┐
│  FULL VIEW (toggled)                                            │
│                                                                 │
│  [User] ──→ [React/nginx] ──→ [FastAPI] ──→ [Chat Orchestrator]│
│                  │                  │               │           │
│             [Cosmos DB]        [ACR]    [Microsoft Foundry]    │
│                             [ACA Env]       [FoundryAgent]      │
│                           [Managed ID]   [SQL Query Tool]       │
│                           [Log Analytics]    [Azure SQL]        │
│                            [Terraform]                          │
│                                                                 │
│  ╌╌ [Microsoft Fabric] (alternative path — not active) ╌╌      │
└─────────────────────────────────────────────────────────────────┘
```

**Color scheme** (using existing CSS variables):
- Joel-configured nodes: `fill: var(--color-accent-soft)`, `stroke: var(--color-accent)`
- Microsoft-provided nodes: `fill: var(--color-surface)`, `stroke: var(--color-line-strong)`
- Fabric alternative: `fill: none`, `stroke: var(--color-line)`, `stroke-dasharray: 4 2`, `opacity: 0.6`
- Arrow lines: `stroke: var(--color-muted)`

**Interactivity**:
- Each node `<g>` has `data-label` and `data-detail` attributes
- Vanilla JS `mouseover`/`mouseout` toggles a `<div id="arch-tooltip">` positioned via `getBoundingClientRect()`
- A `<button>` below the SVG toggles the `hidden` attribute on the full-view `<g>` group
- The simplified view `<g>` is toggled off when the full view is shown

**Accessibility**:
- `<svg role="img" aria-labelledby="arch-title">`
- `<title id="arch-title">Architecture diagram: Agentic data application on Azure</title>`
- Static text description immediately below SVG (FR-016 fallback)
